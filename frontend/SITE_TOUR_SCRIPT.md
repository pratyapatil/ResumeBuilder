# ResumeCraft Site Tour Script

## Voiceover

1. ResumeCraft helps users create job-ready resumes faster with guided editing, live preview, AI feedback, and export options in one workspace.
2. The layout is simple: editing controls on the left, live resume preview on the right, so every change is visible immediately.
3. Users can build each section step by step, including personal information, summary, experience, education, projects, certifications, languages, and custom sections.
4. When they want a different presentation style, they can switch between ATS-safe templates and more visual designer layouts.
5. If they already have an old resume, they can paste the text and let ResumeCraft extract structured details into the editor.
6. Layout controls make it easy to reorder sections or hide less relevant content for a specific application.
7. The AI analysis tab compares the resume to a target job description, highlights missing skills, and suggests improvements to strengthen ATS alignment.
8. Once everything looks right, users can export a polished PDF or a Word document for sharing, editing, and recruiter workflows.
